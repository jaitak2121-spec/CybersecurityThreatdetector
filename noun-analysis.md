# Noun Analysis

1. Candidate Nouns
The following nouns were identified from the problem statement and use cases:
* Security Event
* Login Event
* File Access Event
* Network Event
* Threat
* Threat Detector
* Detection Rule
* Alert
* Risk
* Incident
* Investigation
* Evidence
* Response Action
* Device
* Security Log
* Security Report
* Security Analyst
* System Administrator
* Account
* Source IP
* Severity
* Status

2. Filters Applied

The candidate nouns were filtered to identify the main domain entities of the system.

| Filter                      | Candidates                                    | Action                                                       |
| --------------------------- | --------------------------------------------- | ------------------------------------------------------------ |
| Actors                      | Security Analyst, System Administrator        | Removed — these are users/actors interacting with the system |
| Processes                   | Investigation                                 | Removed — represents an activity rather than an entity       |
| Duplicate/Specialized terms | Login Event, File Access Event, Network Event | Merged under **SecurityEvent**                               |
| Attributes                  | Risk, Source IP, Severity, Status, Account    | Treated as attributes rather than separate entities          |
| System component            | Threat Detector                               | Removed — represents system functionality                    |

3. Survivors

After applying the filters, the following nouns were selected as the main domain entities:

| Entity             | Purpose                                                                    |
| ------------------ | -------------------------------------------------------------------------- |
| **SecurityEvent**  | Represents a security-related activity detected or generated by the system |
| **Threat**         | Represents a potential cybersecurity threat                                |
| **DetectionRule**  | Defines the logic used to identify suspicious activity                     |
| **Alert**          | Represents a warning generated when suspicious activity is detected        |
| **Incident**       | Represents a security issue requiring investigation or response            |
| **Evidence**       | Information used to investigate a threat or incident                       |
| **ResponseAction** | Represents an action taken in response to an incident                      |
| **Device**         | Represents a device involved in or affected by an incident                 |
| **SecurityLog**    | Stores records of security-related activities                              |
| **SecurityReport** | Provides a summary of security information                                 |

4. Final Survivors

```text
SecurityEvent
Threat
DetectionRule
Alert
Incident
Evidence
ResponseAction
Device
SecurityLog
SecurityReport
```

These surviving nouns form the initial domain entities for the **Cybersecurity Threat Detector**. They will be used as the basis for further analysis of classes, attributes, responsibilities, and relationships.
